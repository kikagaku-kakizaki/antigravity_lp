# AI Web制作 LP 改善計画書 (IMPROVEMENT_PLAN.md)

## 1. 競合3サイトの詳細分析と抽出された課題
指定された競合3サイトの詳細分析に基づき、それぞれの「勝てる要因」と自社LPのギャップを整理しました。

### ① AIDD (https://aidd.jp/training/aidd/)
*   **強み**: 「生産性55%向上」という**具体的な数値インパクト**と、専門家「せお丸」氏のキャラクターを前面に出した**圧倒的な権威性**。
*   **自社への示唆**: 「2日間でできる」という体験の提示だけでなく、「その後の業務がどう変わるか」の数値的なベネフィット提示が不可欠。

### ② 東京ITスクール (https://tokyoitschool.jp/service/ai-claudecode/)
*   **強み**: **助成金活用（最大75%補助）**による金銭的ハードルの払拭と、エンジニア教育の老舗としての**技術的信頼感**。
*   **自社への示唆**: 法人担当者が上申する際に最も気にする「コスト（ROI）」と「技術的妥当性」への回答を用意する必要がある。

### ③ ThinkMove (https://thinkmove.jp/lp/ai/)
*   **強み**: **Before/Afterの工数比較**（23h→4.5h）の可視化と、「営業なしの無料相談」という**心理的ハードルの低い入口**設計。
*   **自社への示唆**: 「申し込み」の前に「まずは相談」というステップを設け、課題に寄り添う姿勢を見せることがCVR向上の鍵。

### 【自社LPの決定的な不足要素】
*   **ベネフィットの定量化不足**: 経済的メリット（ROI）が不明確。
*   **社会的証明の欠如**: 誰が教えるのか、どのような実績があるのかが見えない。
*   **コンバージョン障壁**: 商談前の「相談」の場が用意されていない。
*   **リスク管理への言及**: 法人導入で必須となるセキュリティ等への配慮が不足。

## 2. 改善戦略： 「即効性と実利」による差別化
大手研修会社の「ブランド力」に対し、本コースは**「圧倒的なスピード（1.5日間）」**と**「具体的成果（自社LPの完成）」**、そして**「投資対効果（外注費ゼロ）」**を全面に押し出すことで勝利します。

## 3. 具体的な改善施策

### ① ファーストビュー（FV）の訴求力強化
*   **内容**: キャッチコピーを「制作パートナーに」から「コスト削減・内製化」を強調したものへ変更。
*   **意図**: 決裁権限を持つ担当者が一目で「これは会社のコスト解決策だ」と認識させるため。

### ② ROI分析セクションの新設
*   **内容**: 「外注 vs 自社AI内製」のコスト比較およびリードタイム比較の図解を追加。
*   **意図**: 合理的な投資判断を促し、1.5日間の研修費用の安さを際立たせるため。

### ③ 講師プロフィールセクションの強化
*   **内容**: 講師の顔写真、Web制作の専門性、AI活用への知見を詳細に記述。
*   **意図**: 「誰から学ぶか」を明確にし、技術的信頼を獲得するため。

### ④ カリキュラムのアップデート
*   **内容**: 「セキュアなAI運用の作法」や「品質管理」の項目を明記。
*   **意図**: 大手企業でも導入・上申がしやすいよう、ガバナンス面の懸念を払拭するため。

### ⑤ コンバージョン経路の多様化
*   **内容**: お問い合わせフォームに「無料オンライン個別相談」の選択肢を追加。
*   **意図**: 即決できないユーザーとの接点を持ち、商談成約率を高めるため。

## 4. 期待される効果
*   **CVRの向上**: 信頼性と妥当性が高まることで、訪問者からのお問い合わせ率を改善。
*   **商談化率の向上**: 「無料相談」の設置により、確度の高い見込み客との接点が増加。
