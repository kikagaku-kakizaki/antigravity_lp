# Antigravity（AI Web制作研修） LP改善プラン
**Role:** リサーチャーエキスパート / UXデザイナー
**Date:** 2026-03-18

## 1. 競合調査のサマリー
法人向け「AIエディタ・生成AI研修」市場を牽引する主要3サービスの共通点と強みを調査しました。

### 競合他社の共通構成と強み
1. **MENTER（AIエディター Cursor研修）**
   - **強み**: 満足度（平均9.1点）の数値化と、所要時間・参考価格の透明性。
   - **構成**: 「非エンジニアでもDX推進が可能」というメッセージング。
2. **AIDD（AI駆動開発協会）**
   - **強み**: 「人材開発支援助成金」の活用を明確にアピール。実質負担額を大幅に下げる提案。
   - **構成**: SES企業の待機期間活用など、具体的なペルソナに向けた刺さるユースケースの提示。
3. **Track / トレノケート等の大手IT研修**
   - **強み**: 開発効率化（20〜50%向上）の具体的データ提示と、ガバナンス・著作権リスクへの対応（企業が最も懸念する点をクリア）。
   - **構成**: 2日間の詳細なタイムテーブルと、到達レベルの明確な定義。

## 2. 現状の自社LPの「内容が薄っぺらい」根本原因
現在のLPはデザイン面（UX/UI）は高品質に仕上がりましたが、**「法人決裁者を動かすための客観的情報（コンテンツ）」が不足**しています。

- **❌ 実績・事例の具体性不足**: 「最大80%削減」の根拠となる事例や、実際に受講生が作った成果物のビフォーアフターがない。
- **❌ 研修スケジュールの透明性**: 「1.5日間集中」と謳っているが、Day1・Day2で具体的に何を時間割で行うのかが見えない。
- **❌ 法人決裁者向けのキラーコンテンツ不在**: 助成金の活用可否や、企業が懸念する「セキュリティ・著作権リスク」への明確な回答が薄い。
- **❌ FAQ（よくある不安の解消）の欠落**: 初心者が陥る「プログラミング未経験でも本当に大丈夫？」という不安を取り除くセクションがない。

## 3. 次期改善プラン（具体的な追加セクション）

これらの課題を解決し、LPの説得力を競合レベル、あるいはそれ以上に引き上げるための実装プランです。

### 追加セクション①: 「圧倒的な開発事例（Before / After）」
- **目的**: 「本当に自力で作れるのか」という疑念を払拭する。
- **内容**: 
  - (例) 「架空の採用LP」の制作事例。外部委託（100万円・1.5ヶ月）→ 本研修を受講した非エンジニア担当者（0円・2日）という具体的なスクリーンショットと証言。

### 追加セクション②: 「1.5日間の詳細タイムテーブル」
- **目的**: 研修内容の透明化と、投資対効果の正当性アピール。
- **内容**:
  - **Day 1（基礎と設計）**: AIエディタの基本、プロンプトエンジニアリング、セキュアなAI活用ルール。
  - **Day 2（実装と公開）**: Antigravityを用いた実践コーディング、GitHub Pagesでの公開、運用フロー。

### 追加セクション③: 「人材開発支援助成金・福利厚生の活用案内」
- **目的**: 導入担当者の「予算確保のハードル」を劇的に下げる。
- **内容**:
  - 「厚生労働省の人材開発支援助成金が適用可能な場合があります（受講料の最大75%補助等）」といった案内バッジと詳細リンクの設置。

### 追加セクション④: 「FAQ（よくあるご質問）」
- **目的**: 問い合わせ前の疑問を解消し、CVRを高める。
- **内容**:
  - Q. プログラミング完全未経験ですが大丈夫ですか？
  - Q. 持ち込むPCのスペック要件はありますか？
  - Q. 作成したコードの著作権や機密情報の扱いはどうなりますか？（ガバナンスの強調）
