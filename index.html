対象となる方

こんなお悩みはありませんか？

Web制作や生成AIの活用で、多くの方が直面している課題です。

内製化へのハードル

Web制作の専門知識がないため、自社サイトやLPの軽微な修正・更新すら外部ベンダーに依頼しなければならず、時間とコストがかかっている。

AI活用のボトルネック

生成AIツール（Antigravityなど）を導入してみたものの、「制作パートナー」として実務のフローにどう組み込めばよいか、具体的な使い道がわからない。

技術的な不安

環境構築やサーバーの知識がなく、Webページを成果物として公開する「最後の一歩」が踏み出せない。

独自のカリキュラム

Antigravityを「制作パートナー」に

2日間のハンズオンを通じて、実務で使えるWebサイト構築プロセスを習得します。

01

要件整理と設計

Antigravityとの対話を通じて、目的・ターゲット・構成を明確にし、実装計画（Implementation Plan）を共創・承認するフローを学びます。

02

AIと進めるコーディング

HTML/Vanilla CSS/JavaScriptを用いたモダンでプレミアムなデザインの静的サイトを、Antigravityに指示を出しながら効率的に実装します。

03

検証とブラッシュアップ

ローカルサーバーでの表示確認や、UIのマイクロインタラクションの調整など、クオリティを一段引き上げるためのAIへの適切なフィードバックサイクルを回します。

研修のゴール

「自力で公開できる」が
あなたの自信に。

  • 外部ベンダーや専門職に頼らず、実用的なサイトを短時間で構築
  • GitHub Pagesの利用により、無料でセキュアなホスティング環境を構築
  • 受講後、実際に公開・改善を回せる「自分だけのLP」が手元に残る
