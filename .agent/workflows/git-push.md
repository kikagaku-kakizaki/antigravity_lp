---
description: 【研修用】Git デプロイ（メッセージ自動提案・編集可）
---

このワークフローは、現在作業中のディレクトリ（ワークスペース）の変更を Git に保存し、リモートレポジトリへ送信します。

1. 変更されたすべてのファイルをステージングに追加します。
// turbo
run_command: git add .

2. 現在の変更内容（diff）を分析して、適切なコミットメッセージを 1 つ提案してください。
   提案後、ユーザーに「このメッセージで良いか、または任意のものに変更するか」を確認してください。

3. ユーザーが承認（または新しいメッセージを入力）したら、その内容でコミットを実行します。
run_command: git commit -m "[AI suggested or user provided message]"

4. リモートレポジトリの作業ブランチへ送信します。
// turbo
run_command: git push origin [作業ブランチ]
